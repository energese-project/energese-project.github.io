Energy Systems Language · executable · citable

One model. Simulate it, draw it, publish it.

Energese is a toolchain for Howard T. Odum’s Energy Systems Language. A system is described once, as a JSON document of storages, sources, sinks and the pathways between them. From that one document comes a numerical simulation, a publication-quality diagram, and a browser editor — not three separate artefacts that have to be kept in step.

The problem we are working on

The figure drifts from the model

A diagram in a paper is usually a drawing kept beside the model it depicts, and the two come apart. Here the figure is a function of the model: change a transformity or add a pathway and the figure follows, because nothing about the picture is stored anywhere else.

The language was never executable

Odum’s symbols — source, storage, heat sink, interaction, gain, loop-limited converter, exchange, switch — are a complete vocabulary for systems dynamics, but they were a notation. Each one is now a node primitive with defined semantics, and an unrecognised type is an error rather than a silent default.

Energy and money need one set of books

A model tracks energy, material, money and information across the same network. The open question is whether one artefact can be a faithful Odum simulation, an emergy evaluation, and a set of books an accountant may rely on. That is the subject of the conformance work.

How the pieces fit

One model document, three consumers. The kernel is the only implementation of the dynamics; the editor and the diagram package read the same file rather than re-interpreting it.

What we hold ourselves to

Claims are checkable by running something
Every quantitative claim in the papers is the output of a program, and the program is public. A number is cheaper to refute than a position is to defend.
Limits are stated, not discovered later
Where the kernel is a faithful Odum simulator and where it is not yet a faithful implementation of the emergy algebra are both written down, with the measurement that shows it.
Results pin to an exact version
Each release is archived with its own DOI, so a published result can name the code that produced it rather than a moving target.
Silence is a bug
A mistyped node type, an unknown key, an unstated price: each is a load-time error. A default that quietly stands in for a missing value produces a model that looks right and is wrong.
